# 项目总览 V1.4

## 产品

知乎 Run 是一个面向学生和职场新人的 Executable Knowledge 产品。它把适合执行的知乎方法型内容编译成稳定的交互式 Run，让用户在真实行动时逐项确认、回看原文依据、保存进度并得到结果摘要。

## 用户价值

用户缺的不是另一段回答，而是把已认可的方法真正执行一遍的工具。Run 降低找步骤、记状态、防遗漏和核对出处的成本。

## AI 价值

AI 负责判断内容是否适合执行、把原文结构映射为受限交互 Schema，并为关键动作建立来源锚点。运行时不调用 AI，从而保证同一个 Run 稳定、可恢复、可复查。

## Hero

- 人群：求职或初入职场的学生与新人。
- 场景：根据知乎方法型内容完成求职材料自检。
- Grammar：Inspect。
- 屏幕证据：风险状态变化、查看来源高亮、完成后的自检结果。
- Source：必须由真实知识详情接口提供；默认简历自检，不满足条件时仅在同一人群与 Grammar 内替换题材。

## 交付边界

P0 是一个完整 Hero、两个 Supporting Run、五个用户页面、编译与发布内部闭环以及提交前公网 Demo。数量、排行、公开编译和完整后台都不构成产品完整性；OAuth 仅作为不阻塞主链路的可选 P1。
