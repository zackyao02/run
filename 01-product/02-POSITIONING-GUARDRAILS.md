# Positioning Guardrails

## 必须说

- Executable Knowledge
- Knowledge Compiler
- Knowledge Runtime
- Existing Knowledge → Executable Version
- Compile Once, Run Many
- Source-bound
- Started / Completed

## 可以说

- “内容本身是程序的来源”
- “给知乎知识增加 Runtime”
- “让方法型知识拥有状态、完成条件和使用信号”

## 不再把这些当核心创新

- 从知道到做到
- 从内容到行动
- 帮你走出下一步
- 看完以后马上做
- AI 把文章变成一个小工具
- AI 生成互动内容

这些表达过宽，容易与 Action Agent、互动内容、App Builder 撞车。

## 禁止承诺

- Completed = 问题解决
- Started/Completed = 知识更正确
- Run 自动扫描整个知乎
- Run 已经原生写回知乎 App
- Search 摘要 = 完整原文

## 产品边界测试

任何新功能先问：

> “它是在增强 Knowledge Compiler / Runtime，还是把 Run 拉回一个普通 AI Agent？”

若属于后者，P0 拒绝。
