# Submission Checklist V1.4

## 硬性提交

- [ ] 公网 Demo 无需本机服务，评委可直接操作。
- [ ] 产品说明清楚解释用户、痛点、AI 价值、技术方案和知乎生态价值。
- [ ] 链接、文字与版本在截止前完成最终确认。

## Demo

- [ ] 首页与知识详情免登录可见；点击「RUN」后完成知乎 OAuth，授权回跳保持原 Run。
- [ ] 手机 4G/5G 异网实测。
- [ ] 前 20 秒看到用户价值。
- [ ] 3 分钟内完成操作、来源证据和 Result。
- [ ] 已连续完整彩排 3 次。
- [ ] 备用演示视频与当前版本一致。

## 真实性与安全

- [ ] Hero 来自真实 Full Source；Supporting 来自 Full Source 或范围明确的赛事官方详情片段。
- [ ] 所有 Bounded Source Excerpt Run 均持续显示覆盖范围，未声称代表整篇文章。
- [ ] fixture、测试计数和模拟身份没有伪装成线上使用数据。
- [ ] 没有 Key、Secret、Token、个人敏感信息进入仓库或前端。
- [ ] 开发日志和 AI 交互记录真实留存，未修改时间线。

## 可选加分

- [ ] 代码仓库已在确认资格与公开时点后准备提交。
- [ ] 演示视频链接可访问。
- [ ] 离线 Baseline 或编译评测可用于答辩，但不阻塞硬性提交。
