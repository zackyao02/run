## 项目概况

- 项目：知乎 Run｜用一下
- 形态：Next.js 移动端 H5 / Web App
- 运行环境：Node.js + PostgreSQL（公网部署）
- 关键入口：发现、详情、运行、Result、我的、内部 Preview/Publish

## 目录导航

- `app/`：页面与 API 路由
- `src/components/`：运行器、卡片、来源依据、AI 解读等 UI
- `src/domain/`：编译、运行时、锚点、持久化和 Provider 领域逻辑
- `spec/`：可执行 Run、Judge、OpenAPI 和产品约束
- `db/migrations/`：数据库迁移
- `tests/`：编译与来源锚点测试样例
- `04-delivery/`：交付、部署、彩排和本提交材料

## 本地检查

```text
npm install
npx tsc --noEmit

```

## 仓库安全说明

- 不提交 `LLM_API_KEY`、知乎 App Key、OAuth Token、数据库密码或 Operator Secret。
- `.env` 只保留在部署平台或本地未跟踪文件中。
- 公开仓库前检查截图、日志和演示视频，确认没有凭证、个人信息或内部接口密钥。
