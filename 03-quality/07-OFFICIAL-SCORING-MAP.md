# Official Scoring Map

## 初审

官方开发者手册：
- AI 场景价值：40%
- 创新度：25%
- 完成度：25%
- 产品体验与设计：10%

## 决赛

- AI 场景价值：35%
- 创新度：25%
- 完成度：25%
- 产品体验与设计：8%
- 计划书和演示：7%
- 3 分钟 Demo + 2 分钟 Q&A

## Run 对应策略

### AI 场景价值
证明：
- 静态方法型知识存在真实执行摩擦；
- Run 不只是换一种展示；
- Result Artifact 与 Usage 有真实用户价值。

### 创新度
重点只讲：
- Executable Knowledge Object
- Compile Once, Run Many
- Source-bound Runtime
- Usage Trace

不要用“互动内容”“从内容到行动”做主创新。

### 完成度
- 真实官方 Full Source 链路
- 1 个精修 Hero + 2 个 Supporting Run
- Runtime 断 LLM 仍可用
- 幂等 Started/Completed
- Source Evidence

### UX
- 10 秒知道 Run 能干什么
- 不是 Workflow UI
- Result Artifact 清晰

### 计划书/演示
- 3 分钟不讲大而全架构
- 先展示新对象，再证明 Compiler
