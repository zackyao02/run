# Risk Register V1.7

| 风险 | 级别 | 触发信号 | 最小应对 |
|---|---|---|---|
| Hero 像普通 Checklist | 极高 | 评委看不到来源与编译差异 | Hero 必须展示 Anchor 高亮和 Result |
| Full Source 数量不足 | 极高 | 只有一个可确认完整的知识来源 | Hero 保持 Full Source；Supporting 使用带覆盖范围披露的官方详情片段 |
| 片段被误解为整篇文章 | 极高 | UI 出现“整篇已编译”或缺少范围提示 | 卡片、运行页、Result 持续显示覆盖范围；发布前自动检查 |
| AI 价值说不清 | 极高 | 演示只剩勾选 | 展示 Judge/Compiler/Validation 证据，不要求现场生成 |
| Source Anchor 错位 | 极高 | 高亮与 quote 不一致 | 发布前逐项自动校验，Hero 人工复核 |
| 范围再次膨胀 | 高 | 出现排行、公开编译、完整后台 | AGENTS 与冻结文件一票否决 |
| 现场 LLM/接口超时 | 高 | 编译超过演示预算 | Hero 使用已发布版本；实时编译仅加分 |
| Session 语义错误 | 高 | 点击开始就计 Started 或重复计数 | 事务幂等测试 |
| Completed 被说成现实成功 | 高 | Result 出现结果保证或新建议 | Result 只聚合 Progress |
| 凭证泄漏或编译滥用 | 高 | 前端出现 Secret 或公共入口 | 内部受保护流程、并发 1、预算限制 |
| 公网链接不可访问 | 高 | 异网或手机打不开 | 提交前异网测试和备用录屏 |
| 提前公开影响资格 | 高 | 赛前公开仓库或产品宣传 | 以官方口径为准；部署与公开作为提交前门禁 |
| OAuth P1 阻塞 | 低 | 登录流程未完成 | 不阻塞 P0 Run；未配置时显示部署后可用 |
